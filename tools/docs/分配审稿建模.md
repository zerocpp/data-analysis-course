## 二、Reviewer 矩阵层设计

### 2.1 数据流

```
Ingest 完成的 Registry（PASS + INGESTED 才可入池）
  → input_builder   reviewer_order = student_id 排序
                    task_order[i]  = 第 i 人的 own task（配对序 ⇒ 对角线=自评）
                    category_vector = 14 类 FM 索引（1..14）
  → solver.solve_assignment(category_vector, r, seed, config)
  → verifier        硬约束从零重算（不信任 solver 内部校验）
  → evaluator       多样性审计分（生产侧非验收门）
  → mapping + distribution  私有映射 / 匿名分发（12 项禁词防泄漏）
  → READY
```

- 输入快照 sha256 可复现；seed 缺省由快照 hash 派生（同快照 + 同 policy ⇒ 同分配）。
- 幂等：相同 (snapshot, method, seed, policy) 的 run 直接复用（`RUN_EXISTS`）。

### 2.2 Verifier 硬约束（全部必须满足，违反即 VERIFICATION_FAILED）

1. 矩阵恰为 n×n 且每行 n 列；
2. 全矩阵 binary（元素 ∈ {0,1}）；
3. 每 reviewer 行和 = r（评审负载一致）；
4. 每 task 列和 = r（任务覆盖一致）；
5. 对角线全 0（**禁自评**）；
6. 无重复 reviewer–task pair；
7. 禁止静默 fallback（`no_silent_fallback=true` 为 policy 硬性要求）。

### 2.3 五种求解方法（Phase B 冻结；唯一实现在 `assignment/solver.py`）

| 方法 | 一句话思路 | 多样性得分（基准 Overall） |
|---|---|---|
| RANDOM_FEASIBLE | seeded 置换共轭的 r-offset 循环，仅保证可行性 | 84.00 |
| CATEGORY_AWARE_GREEDY | 构造期贪心：未覆盖类别优先 → 剩余容量 → seeded tie-break | 84.12 |
| RANDOM_SWAP | 从 M1 出发随机合法 swap 全接受（无目标基线） | 84.09 |
| **CATEGORY_AWARE_SWAP**（生产默认） | 目标引导局部搜索：仅当同类 collision 总数下降才接受 swap；tie 由 seeded coin（p=0.5） | **93.05** |
| OPTIMIZED_ASSIGNMENT | 精确 Min-Cost Max-Flow（凸边际成本），确定性上界 | **93.05** |

policy 关键参数（`policy/assignment_policy.json`）：`reviews_per_task = tasks_per_reviewer = 10`（v1 要求相等）、
`max_swap_iterations = 100000`、`tie_accept_probability = 0.5`、`max_restarts = 100`、
`anti_self_review = true`、`duplicate_pair_rule = forbidden`。

### 2.4 评分（`assignment/evaluator.py`；生产侧仅审计，Benchmark 侧为冻结主评分）

- **主指标 CATEGORY_PAIR_DIVERSITY**：`a_ic` = reviewer i 手里类别 c 的 task 数 →
  `collision_i = Σ_c C(a_ic, 2)` → `D_i = 1 − collision_i / C(r,2)` → `score = 100 × mean_i(D_i)`。
- **诊断指标 exposure MAE**（不进分）：`a_ic` 与理论期望 `mu_ic = r·(M_c − I[c_i==c])/(N−1)` 的平均绝对偏差。
- 附 reviewer 级 D_i 分布（mean/std/min/max/median/P10/P25/P75/P90）。

### 2.5 流程状态机与错误码

- 正向 7 态：`INPUT_PREPARED → SOLVED → VERIFIED → MAPPED → DISTRIBUTION_BUILT → DISTRIBUTION_VERIFIED → READY`
- 终态失败 5 种：`INPUT_INVALID / SOLVER_FAILED / VERIFICATION_FAILED / MAPPING_FAILED / DISTRIBUTION_FAILED`
- 结构化错误码 4 组共 28 个（输入 12 / solver-verify 7 / mapping-distribution 9），
  分发侧 `PRIVATE_CONTENT_TOKENS` 12 项禁词（reference.py / gold / owner_student_id 等）。

## 三、Phase 1 层设计（FM 分层 Min-Count 采样）

方法：`fm_stratified_min_count_sampling`（`phase1/assignment.py:46`，唯一正式方法；
legacy balanced_cyclic_shift / late_exact / late_greedy 仅历史复现，正式 build 禁用）。

每 reviewer 两轮：

1. **Round 1（FM 分层）**：打乱 FM01–FM14 顺序，每个 FM 最多采 1 个 task（保证 FM 覆盖面）；
2. **Round 2（fill）**：全局候选补足至 m=15——优先 `selection_count` 最低
   （均衡暴露），同分优先该 reviewer 未覆盖的 FM，最后 seeded 随机 tie-break。

合法性三硬规则（每步同时满足）：

1. 禁自评：`owner(task) != reviewer`；
2. reviewer 内无重复 task；
3. 单 task 全局暴露 ≤ cap = m+1 = 16（跨 reviewer 有放回、reviewer 内无放回）。

可复现性：全部随机性来自单个 `random.Random(seed)`；reviewer 顺序先 shuffle（禁固定 id 序）。
守卫：池不足 → `INSUFFICIENT_MAIN_POOL`；Round 2 无合法候选 → `CAPACITY_EXHAUSTED`；
硬约束断言 A–G（每人恰 m / 无重复 / 无自评 / count≤cap / 均来自 frozen pool / 正反映射互逆）。

**Late 语义**：frozen main pool 只读；late 学生复用同一算法（`LATE_METHOD = MAIN_METHOD`），
以当前 selection_count（main + 之前 late 累计）为初值单独采样；每 late 学生独立 seed 去相关；
late task 允许 0 reviewers；**绝不修改已冻结的 main 分配**，合并亦不得突破 cap。

### 4.2 多样性基准（`benchmark/assignment_diversity_v1`，结果冻结于 STUDY.md）

协议：10 个冻结合成 case（N=200，类别 universe 1..14；三族：balanced_mild / long_tail /
extreme_boundary）× 5 方法 × 每 case ≥30 seeds；主实验 r=5，共 1210 次运行，
**0 次 hard-gate 违规**；输入以 hash `5b005cc5a08337e6…` 锁定，运行前后校验。

| 方法 | Overall macro | Balanced | LongTail | Extreme | SeedStd | 均耗时 |
|---|---|---|---|---|---|---|
| OPTIMIZED_ASSIGNMENT | **93.05** | 100.00 | 92.00 | 90.62 | 0.000 | 0.223s |
| **CATEGORY_AWARE_SWAP**（生产默认） | **93.05** | 100.00 | 92.00 | 90.62 | 0.002 | 0.252s |
| CATEGORY_AWARE_GREEDY | 84.12 | — | — | — | — | — |
| RANDOM_SWAP | 84.09 | — | — | — | — | — |
| RANDOM_FEASIBLE | 84.00 | — | — | — | — | — |

per-case 均值（RF / Greedy / R.Swap / **C.Swap / Optimized**）：

| Case | 族 | C.Swap / Optimized |
|---|---|---|
| C01 近均衡 | balanced | **100.00 / 100.00** |
| C02 轻偏 | balanced | **100.00 / 100.00** |
| C03–C05 | long_tail | 99.75 / 95.50 / 90.75 |
| C06 长尾最强偏斜 | long_tail | 82.00 |
| C07 单主导(100) | extreme | 80.00 |
| C08 双主导(60/50) | extreme | 92.50 |
| C09 单例尾部 | extreme | 92.46 / 92.50 |
| C10 缺类边界(4 空类) | extreme | 97.50 |

**关键结论**：

1. 生产默认 `CATEGORY_AWARE_SWAP` 逼近精确最优（Overall 并列 93.05，仅 seed 波动 0.002）；
2. 相对随机可行性基线 **+9.05 分**，相对误差缩减 ≈56.6%；
3. 均衡/轻偏类别分布（C01/C02）达到满分 100.00；差距只出现在极端偏斜分布
   （单主导类别理论上限受限，非算法缺陷——OPTIMIZED 亦为 80.00）；
4. 类别感知 Greedy 与无目标 Swap 得分几乎相同，说明**收益来自"目标引导"而非"局部搜索"本身**。
